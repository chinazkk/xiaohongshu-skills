# 小红书调研报告模板

报告必须有：结论、研究问题与样本、核心发现表、决策建议、反证与风险、来源索引、来源与证据边界。旅行或购买问题还必须有能实际执行的日程/下单顺序/Plan B 和实时复核项。

## 引用写法

正文每项实质判断后标出证据编号，例如：

```markdown
卡塔适合作为短行程基地，但海上项目应保留取消空间。【XHS-02】【XHS-C04】
```

报告末尾必须提供可点击的完整来源索引：

```markdown
## 来源索引

- 【XHS-02】[卡塔 6 天实录](https://www.xiaohongshu.com/explore/example)
- 【XHS-C04】[雨季实录评论区](https://www.xiaohongshu.com/explore/example)
```

不要把小红书的个人体验写成官方规则、实时价格或代表性调查。
